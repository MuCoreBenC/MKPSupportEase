# 客户端文案问题清单（总索引）

> 判据是 `docs/COPY-STYLE.md`。这叠清单只做一件事：把界面上**开发者腔、重复、长句、
> 括号补丁**挑出来，给出四语建议，逐条等批注。
>
> **本轮不动界面、不动字典**。有字段一律保留：这里改词，不删信息，不改分组与折叠状态。

## 一、怎么批

每条一行，第一列是 `☐`。三个按钮的意思：

| 按钮 | 含义 |
| --- | --- |
| **同意** | 按建议改（四语一起落） |
| **不改** | 保留现在的文案，这条跳过 |
| **自己写** | 用你写的那句；只填中文，繁 / 日 / 英 我按意思补 |
| **＋ 备注** | 只给我看的一句话（不落进界面），可以和上面三种任意组合 |

再点一次同一个按钮 = 取消。四语列给的是**建议**，不是定稿。
旧版按钮叫「用 / 弃 / 改」；写在「改」里恰好是「同意 / 同意备注」的，打开时会自动认成**同意**。

## 二、问题类型（固定八类，便于整页批量取舍）

| 代号 | 类型 | 判断 | 典型 |
| --- | --- | --- | --- |
| A | 机制解释 | 在讲软件内部怎么运作 | 「云端那份一直留着，不会丢什么」「BBS 已经把它同步到你的账号云端」 |
| B | 括号 / 破折号补丁 | 主句后面挂一段解释 | 「已是最新（云端发布前进过…）」「已复制 x —— 原文件一个字都没动」 |
| C | 一处说三遍 | 同一事实在行、详情、顶部重复 | 「已是最新」在行状态与详情各来一遍 |
| D | 长句 / 从句套从句 | 一句话两三个分句 | 「你机器上那份当初基于的不是云端现在这一版（云端换过版了）」 |
| E | 字段名当句子 | 内部名词直接上屏 | 判定、基线、目录发布、来源发布线、补齐字段 |
| F | 口语赘词 / 安抚尾巴 | 这一份、那一份、的话、随时、一个字都没动 | 「它正在被使用的话，会一并撤下」 |
| G | 元话术 | 谈软件自己，而不是用户的事 | 「连不上时如实说没查到，不冒充『已是最新』」 |
| H | 说明代偿布局 | 文字删不掉，是因为布局没交代 | 页脚把右键菜单十几项列一遍 |

## 三·六、审查台（review.html）

双击 `docs/copy-audit/review.html`，浏览器直接打开，不用起服务。

- 每条显示：键名、**界面位置**（页面 › 分组）、**字典行号**（`zh-CN.ts:1640`，点一下复制）、
  问题类型、现文案、四语建议。
- 每张卡先说**现文案**（已经改好的），下面灰掉划掉的是**旧文案**，留作复盘。
- 三个按钮：`同意` / `不改` / `自己写`；「＋ 备注」只给我看，不落界面。
- 顶部有「未复核」筛选（默认同意改掉、还没看过的 332 条）与「只看建议 30」。
- `导入批注` 读之前导出的 `.md` 或 `.json`；批注存在 localStorage；`清空` 只清批注。
- `导出批注` 下载一份 Markdown（按页面分组、只含已批条目）——把这份放回
  `docs/copy-audit/` 我就能照它落字典；`导出 JSON` 供精确回读。
- 换浏览器、清缓存、无痕窗口都会丢批注，批完先导出。

## 三·七、优先级怎么排

分数不是拍脑袋，三个因子各 1–3 分：

| 因子 | 3 | 2 | 1 |
| --- | --- | --- | --- |
| 可见度 | 首屏就看见 | 点开 / 右键 / 悬停才看见 | 出错或深层设置才看见 |
| 危害 | 会让人看错结论 | 啰嗦但看得懂 | 只是语气 |
| 复用 | 同一句反复出现 | 单处 | 一次性文本 |

`分 = 0.45×可见度 + 0.40×危害 + 0.15×复用`，再按类型微调：字段名当句子 +3、重复 +2、
纯语气 −3、布局欠账 −4。满分 100，四档：

| 档 | 分 | 条数 | 意思 |
| --- | --- | ---: | --- |
| P0 | ≥85 | 58 | 会让人做错判断 |
| P1 | 70–84 | 69 | 值得顺手改 |
| P2 | 55–69 | 269 | 啰嗦，不影响做事 |
| P3 | <55 | 109 | 诊断与深设置，可以最后 |

**前 30 条是人工排的**（卡片上写 `建议 1`…`建议 30`）：分数只能区分「多严重」，
排不出「先改哪句最省事、连带修好几处」。看这一批点顶栏的「只看建议 30」。
其余 475 条按分数排，用 P0/P1 筛。

可以先不动的约 86 条：报告页 52（诊断视图，字段多且低频）、编辑器与对比台 17、
高级设置 7、工艺页窗口胶囊 6、校准页模型缓存 4。批的时候整块写「弃」也行。

## 四、落地顺序（批完之后）

1. 按页改 `src/i18n/zh-CN.ts` → `en.ts` → `zh-TW.ts` → `ja.ts`，四本同一条键一起换。
2. `npm run check:i18n`（键集 / 占位符 / 空值）。
3. 起客户端，按 `docs/UX-SCENARIO-TEST.md` 的规矩再看一遍：删掉说明之后，
   第一次用的人还说不说得出「下一步点哪里」。
4. 布局问题（H 类）不在文案里解决，另开一轮。

## 五、边界

- 不含 `src/workbench/**`（开发台）。
- 不含 `mock.*`（开发预览用的假场景）。
- 不含参数名与参数说明（在 `presets/registry/param_registry.toml`，是数据不是句子）。
- 不含后端渲染的句子（`crates/postprocess/messages.toml`），那一侧同一套写法另开一轮。
