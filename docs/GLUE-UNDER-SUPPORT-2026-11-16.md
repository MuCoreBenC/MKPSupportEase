# 边缘带支撑免抬（下方支撑余量，lab 试验记录）

> 状态：已进内核，并成为预设参数 `wiping.glue_edge_skip_margin`（0 = 关闭免抬）。
> 本文保留当时的判据口径。

## 1. 它想回答什么

一条涂胶线落下去，**笔下面是实的还是空的？离实的边界还有多远？**

- 余量够 → 笔就算按 XY 偏差飘一点，也还在支撑上 → **不必抬**。
- 余量不够（贴边、或下面就是空的）→ 按原来的「边缘带」判定处理（抬）。

这条判据与「边缘带」并列，不覆盖它：边缘带看「离涂胶区域的边多远」，这里看「离下方材料的边多远」。

## 2. 承托面取哪一份

**动作之前最后打印的那一层**里的支撑材料：

| 动作 | 取哪一层 | 为什么 |
| --- | --- | --- |
| 涂胶块（层 L） | L 的**上一层**（小于 L 的最大层） | 涂胶块写在 `; CHANGE_LAYER` 之后、这一层开打之前，笔落下去时托着它的是上一层 |
| 熨烫（层 L） | **同层** L | 熨烫是同层最后一道，托着它的是同层刚打的支撑面 |

支撑材料 = `Support`（含 `Support transition`）+ `Support interface`。

- **同一层里所有对象、所有段取并集**：同一片支撑面会被拆成几段写（实测 Z0.9 层里 `Support interface` 出现在两处），只取第一段会漏。
- 不含内墙/外墙/桥接/填充：那些是零件本体，不是承托面。
- 找不到支撑面 → 判「无支撑」，不参与本判据。

## 3. 覆盖图与内孔

沿用 `band.ts` 的 `EdgeField`：0.25mm 格子、3×3 画笔、3-4 倒角距离场。

**填内孔**（`fillHoles`，2026-11-17 改成有条件）：

1. 从覆盖图的四条边做泛洪，泛洪不到的未覆盖连通块就是「内孔」；
2. 逐孔看同一层的**材料覆盖**（支撑 + 零件本体：外墙/内墙/填充/桥接/顶底面）：
   孔里**有料**才把整块填平；
3. 真空气孔原样留着（涂胶走过去仍算贴边，照样抬）；与外界连通的缺口也永远不填。

含义：孔里是零件（墙/填充/桥接）时笔走过去有东西托着，当实心；孔真是空的时候
不许当安全。图 3 那圈方框的四角靠「与外界连通不填」保住。

## 4. 余量怎么算

对一条落笔移动按 0.2mm 采样（含两端）：

```text
margin(p) = p 在覆盖内 ? 到覆盖外边界的距离（已减画笔半径） : 0
移动余量   = min over 采样点
```

单位 mm。0 = 贴边或落在外面；越大越靠中间。

## 5. 判定

```text
有支撑 = 移动余量 >= 阈值（默认 0.50mm）
建议   = 开关打开 && 有支撑 ? '不必抬' : 原预测
```

阈值是顶栏滑杆（0–2mm），拖动即时重算。

## 6. 已知的近似

- 覆盖图是 0.25mm 栅格，余量有 ±0.25 的量化误差；阈值 0.5 时够用，判 0.1 级别的差别不可信。
- 只取「上一层」，不检查更下面（涂胶只接触最近那层表面）。
- 支撑材料按 `; FEATURE:` 分类；切片器换版本、名字变了会落到 `other`，那种块会判「无支撑」而不是静默算错。
