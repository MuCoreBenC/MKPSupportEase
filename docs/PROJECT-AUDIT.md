## 2. 按作者 ①–⑩ 的现状

### ① 设置 → 备份与恢复 —— ⬜ 未开始

- **出处**：作者口径（2026-10-02）+ `HANDOFF` §4/§5、总纲 §1③ 尾、第十二层的预留。
- **已有**：通用导入接收机制（拖拽 / 选择器 / 重名改名 / 边界检查）已立；`.zip` 今天会被
  **如实拒**（没有认领它的导入器）。

### ③ Preset 页剩下的产品功能 —— 🟡 半完成

- **已有（多）**：两轴四表（MKP / 切片器 × 本地 / 云端）、交付四态、批量、归档抽屉、
  **应用**（MKP 线唯一写口）、编辑链（草稿 → 另存 / 写回自己）、搜索、
  切片器**喷嘴 / 层高筛选**、置顶；BBS 查看器是独立页；"基于旧版官方"的关系展示已有。
- **差**：

    只把草稿并进**内存**里的"已保存"层 —— 没有任何 api 写回（实查 `useParams.ts`）。
  - **参数合法性 / schema 校验**没有：客户端不判语义是既定边界，但"参数编辑器"这一层
