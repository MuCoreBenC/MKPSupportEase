# 预设资产库（2026-10-08 作者裁决 · 实施记录）

> 作者原话（整理）：
>
> 「不要叫：云端预设 / 本地预设。也不要叫：已下载 / 未下载。而是只有一个东西：**预设库**。」
> 「**可以显示（云端资源），但不要把"云端"当成一个列表维度**，而是把它变成一个非常轻的
> **状态 / 来源标记**。」「用户根本不需要知道它到底存在 `delivery/` 还是 `presets-mine/`。」
> 「**用户不关心"这个文件在哪里"，用户关心"我要用这个预设"。**」
> 「每一个预设只需要一个非常明确的：**当前使用 ✓**」
> 「官方是模板，我的才是实际工作文件。这两个东西之间最多保留：`源自 A1 Fast` ——
> 是来源信息，**不是身份认证**。」
> 「我的云端**始终就只有一个最新的版本**，没有其他旧版那些。」
> 「**不需要恢复默认值那个功能了** —— 有问题就让用户删掉，重新下一份新的。」
> 「**支持 Ease 不是"云端预设 + 本地预设管理器"，而是一个"预设资产库"。**」

本文是这一版的**规格 + 实施记录**。它**取代**此前三版方案
（"本地 / 云端两张表"、"下载即得工作副本"、"多版本并存 + 隐藏 baseline + 对比台"）。
根规则（四层归属）见 [`DATA-ARCHITECTURE.md`](DATA-ARCHITECTURE.md)；
产品行为见 [`PRESET-PRODUCT-RULES.md`](PRESET-PRODUCT-RULES.md)（头部三次改判块）。

---

## 1. 一句话模型

```text
云端 catalog 里只有一个当前版 —— 它是**模板**；
用户手上的是「我的预设」—— 那是**实际工作文件**；
模板要用就直接用（「使用」，本机没有就按需取回），要改就先「另存为我的预设」；
两者之间只留一条来源信息（源自官方 X）。没有官方版本账、没有旧版、没有归档。
```

**没有**官方历史版本库、**没有**三方合并、**没有**「已下载 / 未下载」、
**没有**「过时 / 需更新」、**没有**「恢复默认值」。

---

## 2. 两条线

### 官方：模板（住内部区，不进用户世界）

```text
catalog.json 的 files 域         云端登记：这份的落点 / SHA / 机型 / 版本
<appDataDir>/delivery/mkp/presets/<原名>.toml    本机落点（**纯缓存**）
```

- 列表里那一行**只有一个当前版**：catalog 换版之后，这一行就是新的那一版；
- 它在本机有没有字节**不显示**：点「使用」时后端按需取回（`use_official_preset`）；
- 「已下载 / 未下载 / 有更新」这一整套词**在 MKP 档退场**（切片器档照旧）。

### 我的：实际工作文件（住用户根）

```text
<appDataDir>/user/presets-mine/<你起的名字>.toml
```

- 只有两条路产生它：「另存为我的预设」（官方 → 我的）与用户自己放进这一格；
- **下载 / 使用都不再自动产生副本**（旧的"下载即得工作副本"退役）；
- 文件头那三行血统照旧跟着它走（`# based_on*`），但**只是来源信息**：
  它不参与"过时"判断，也不影响能不能用。

## 3. 界面：一张表 + 一枚来源小字

```text
预设  [MKP 配置 │ 切片器配置]                                搜索…

● 已应用 A1-fast.toml · A1    ▽ A1        参数对比     共 9 项  官方 6 · 我的 3
──────────────────────────────────────────────────────────────────
A1-fast.toml                                              A1  快拆版     [使用]
官方 · 10-08

我的 A1 高速版                                            A1  快拆版   ✓ 当前使用
我的预设 · 源自官方 A1-fast.toml   [官方模板已更新]
```

- **MKP 档只有这一张表**：官方那几行与我的那几行并排，`来源` 只是副标题那一行小字
  （「官方 · MM-DD」/「我的预设 · 源自官方 X」/「我的预设 · 导入」）；
- 位置那一轴（本地 / 云端）**只剩切片器档**（它那两张表确实是两件不同的事）；
- 列：**名称 / 机型 / 版本 / 操作**（时间那两格挪进展开详情）；
- 操作列只有两种：没在用的给「使用」，正在用的给「✓ 当前使用」（不是按钮）；
- 我的那一行若来源官方换了新版，挂一枚极淡的**「官方模板已更新」** ——
  **这不是"你该更新"**，那份照常能用能改（程序不替他合并）。

菜单：

```text
官方行  使用 / 另存为我的预设 / 置顶 / 查看详情
我的行  使用 / 改这份 / 另存为一份新的 / 重命名 / 在文件管理器中显示 / 置顶 / 查看详情 / 删除
```

**退场的界面件**：位置轴（MKP 档）、「已下载 / 未下载 / 有更新」、「旧版 ×N」徽章、
归档抽屉、「旧版本 N 份」那一格、「下载并更新 N 份」批量行。

## 4. 动作语义（命令面）

| 命令 | 干什么 |
| --- | --- |
| `use_official_preset(fileName)` | **官方那一行唯一的动作**：本机没有（或盘上那份与目录对不上）就**先按需取回**（同一条下载管道：SHA 校验 / 旧份归档 / 原子落盘），再写唯一底账（official 线）。返回 `fetched` 说这次有没有真的取回来 |
| `copy_official_as_mine(fileName, newName)` | **另存为我的预设**：官方 → `presets-mine/<你起的名字>`（官方原文 + 三行血统）。本机没有就先取回；名字过与改名 / 复制同一道门槛，**撞名就拒**；**一个状态都不碰** |
| `apply_active_preset(fileName, 'mine', path)` | 我的那一行的「使用」—— 与原来同一条（认路径、不查 SHA） |

**退场的命令**：`ensure_user_copy`（下载收尾补工作副本）、`get_preset_defaults`
（「恢复默认值」的基准值）。

## 5. 数据层：什么退了、什么还在

| 东西 | 这一版怎么了 |
| --- | --- |
| `catalog.json` | **唯一真相**：官方有哪些预设、每份的落点与 SHA。官方只有一个当前版 |
| `delivery/<catalog.path>` | 还在，但**降级成纯缓存**：界面不显示它的状态，只被「使用」按需读 / 写 |
| `presets-mine/` | 用户的实际工作文件。**不再由下载自动产生** |
| `archive/` | **MKP 档不再消费**（归档抽屉退场）。写盘那一支还在（切片器档照旧），下一期随切片器一起收口 |
| `runtime::versions` + `get_official_versions` | **MKP 档不再消费**（旧版账退场）。命令留着给切片器那一档，下一期收口 |
| `baseline/` | **不再有任何 MKP 用途**（"恢复默认值"退场）。写盘那一支还在（`deliver` 里），下一期随切片器一起收口 |
| `run/active-preset.json` | **不变**：全局唯一、official / mine 两条线、后应用赢 |
| 「下载即得工作副本」（`ensure_working_copy`） | **退役**：副本只能由「另存为我的预设」显式产生 |
| 「恢复默认值」 | **退役**（命令 + 状态 + 参数页那颗按钮 + `baseline` 的那一用途）。参数表退回**出厂值** |

★ **不写任何数据迁移**（项目铁律）：旧的 `baseline/`、`archive/`、旧命名的"我的副本"
原样留在盘上，程序不读、不搬、不删，也不写启动兜底 —— 换命名 / 换路径一律当全新应用。

## 6. 边界（本轮明确不做）

- **切片器档（BBS / Orca）本期不动**：它照旧两张表（本地 / 云端）、照旧四态、
  照旧归档抽屉与批量行、照旧「复制到切片器目录」（未接线那条也在）；
- **不做官方历史版本**：没有版本列表、没有版本切换、没有"恢复到某一版"；
- **不做合并**：官方换版不会碰用户那份，程序也不猜怎么把改动揉进新版；
- **不做「恢复默认值」**（连"当初那版官方"这个概念一起退场）；
- **不做数据迁移 / 不做启动对账**；
- **不做删除官方缓存**的界面入口（那一层是实现细节，不给用户一个他不需要理解的开关）。

## 7. 实施盘点（2026-10-08）

| 层 | 改动 |
| --- | --- |
| Rust 命令面 | 新增 `use_official_preset`（按需取回 + 写使用中）、`copy_official_as_mine`；`download_runtime_file(s)` 去掉收尾建副本；退役 `ensure_user_copy` / `get_preset_defaults`；`runtime::mine` 里 `ensure_working_copy` 一系（`working_copy_of` / `working_copy_name` / `release_date_of` / `available_mine_path` / `numbered`）退场，换成 `save_official_as_new`；两份 `invoke_handler` 清单一字不差地同步 |
| 前端数据 | `presetTree.assetRows`（MKP 那一张表）+ `mineHalf`（两张表共用「我的预设」那一半的映射）+ `ASSET_*` 五组词；`usePresetData` 新增 `useOfficial` / `saveAsMine`；MKP 档 `scope` 恒为 `local`、`cloudBase` 恒空表 |
| 前端界面 | `PresetScopeBar` 只在切片器档画位置轴；`PresetTable` MKP 档 4 列（无时间列）、操作列「使用 / ✓ 当前使用」、名称列挂「官方模板已更新」；`PagePresets` 台账改「官方 N · 我的 N」、右键菜单按来源分两套、新增「另存为我的预设」那一口抽屉、底部右键提示按档说 |
| 消费方 | 首页「下载并应用」→「使用」（`useOfficialPreset`，不再补副本）；校准页话术改「先另存为我的预设」；参数页「恢复默认值」退回出厂值（删掉 `defaultSource` 那一档） |
| 探针 | `scripts/probes/presets.mjs`：位置轴按档判、资源库那一张表的断言、菜单两套、归档 / 批量退场、`data-rowkey` 取文件名（本名里可能有空格） |

`saving_official_as_new_refuses_an_existing_name`、`saving_official_as_new_checks_the_new_name`、
`saving_official_as_new_refuses_non_presets`、`saving_official_as_new_touches_no_state_at_all`。

## 8. 下一期（与切片器一起收口）

切片器那一档还在用旧的几样东西 —— 它们**不是因为 MKP 而留**，是因为切片器没动：

```text
archive/                     换版本留档（四态判定要它当证据）
runtime::versions            官方版本账（切片器的旧版 ×N）
baseline/                    隐藏快照（切片器侧的写入仍在跑，但没有消费者了）
「本地 / 云端」两轴            切片器那两张表
get_official_versions        上面那两样的命令面
```

下一期做切片器那一档时，这几样一起清（还是老规矩：不写迁移，旧目录用户自己删）。
