# 自己拼涂胶区域（布尔交）— 备选方案

> 状态：**未实现**。先记下来，等「下方支撑余量」在 lab 里跑过一轮、判定效果不好时再回来做。
> 本文只描述算法与风险，不承诺接口。

## 1. 现在怎么定涂胶路径

后处理直接沿用切片器给的涂胶路径（`;MKP_BEGIN paint` 块里的 `G1`），只做删改与抬高档。
换句话说：**涂在哪，是切片器（支撑面 / 支撑熨烫）说了算**，我们只决定这一段抬不抬。

作者 2026-11-16 提出：能不能不要跟着它走，自己算「该涂哪」并自己生成路径。

## 2. 物理口径

涂胶要落的位置，本质是两块区域的交：

```text
区域 = 上一层模型压下来的地方（overhang） ∩ 下面那层有支撑的地方（support）
     再向内收：半个笔宽 + 安全余量
```

- **上一层模型**：外墙 / 内墙 / 桥接 / 稀疏填充 / 内部实心填充 / 顶面 / 底面 —— 只要是那一层的挤出都算「压下来」。
- **下面那层支撑**：`Support` / `Support transition` / `Support interface` / `Support ironing`。
- 只取支撑、不取零件本体：零件的墙在孔里，属于「孔里有东西」，不参与边界判定（见 `docs/GLUE-UNDER-SUPPORT-2026-11-16.md` 的内孔口径）。

为什么不能照抄切片器的熨烫面：熨烫是工艺产物，不等于 overhang。实测 `87306.0_20261116_112411.gcode` 第 8 层（Z0.9）：

| | 范围 |
| --- | --- |
| 支撑面（岛 1） | r 2.94 → 6.43（mm，圆心 74.54, 71.50） |
| 支撑熨烫 | r 2.91 → 3.41（只有贴着零件壁的 0.5mm 一圈） |

熨烫并没有铺满整片支撑，它只是一圈。按熨烫涂胶 = 只在那一圈涂；按 overhang ∩ support 涂 = 该涂的地方都涂到。

## 3. 算法（两档精度）

### 3.1 栅格版（lab 试验用，零依赖）

1. 第 N 层支撑、第 N+1 层模型各铺一张 0.25mm 覆盖图（沿线段取样 + 3×3 画笔，让 0.4 间距的批路线连成片）。
2. `overhang = support ∧ model`（逐格 AND），再对内孔做一次填平（与 `under.ts` 同一套：孔里有料才填）。
3. 向内腐蚀：按「半个笔宽 + 余量」的格数做一次腐蚀（或直接用距离场取 `d >= inset`）。
4. 抽轮廓：marching squares → 折线；窄处会断成多段，按长度阈值丢掉碎段。

精度 0.25mm，够看「区域对不对」，不够当产物坐标。

### 3.2 多边形版（要写进内核时）

1. 从切片器的墙/轮廓段重建闭合多边形（外墙一圈、内墙一圈、支撑边界一圈）。
2. `Clipper2`：`overhang = support.Poly ∩ model.Poly`，`region = overhang.Inflate(-inset)`。
3. 偏移与裁剪都在多边形上做，精度微米级；窄颈、自交按 Clipper 的规则收。

## 4. 路径生成

两条路，先选一条：

- **轮廓等距**（跟现在产物里的形状一致）：
  `region` 向内按线距逐圈偏移，得到 N 圈（对应「外几条」）；每圈是一个闭合或开口折线。
  难点：窄处内缩会自交/消失；需要按面积或长度阈值清理；圈与圈之间要连成一条连续路径（否则每圈一次抬笔）。
- **扫描线**（实现简单）：在区域内按线距做 zig-zag，裁剪到 `region` 内；端点落在边界上。
  缺点：与现在的涂胶形状差很多（斜向/圆弧会变成齿状），换向多、抬笔多。

起点/接缝：轮廓等距时选「离上一段终点最近且不在支撑边缘」的点；扫描线时固定在一侧。

## 5. 空走

不是「随便连」：

- 抬笔高度沿用现在的 `GLUE_LIFT`（段间平飞），跨块另算；
- 顺序：段内按最近邻，段间按块顺序；不允许穿过已涂区域（会蹭到胶）；
- 与现有 `;MKP_BEGIN` / `swap` / `;MKP_STAGE:` 的换笔结构拼上：自己生成的是 **paint 块内部**，外面的换笔、抬升、回抽仍由 `glue_block.rs` 负责。

## 6. 与内核接线（风险最大的一段）

`pass1` 现在是「切片器给的涂胶行 → 删改 + 加标记」，自己生成等于：

1. 换掉区域来源（从 `;MKP` 解析出来的路径 → 自算区域）；
2. 换掉整段 paint 块（路径、Z、E、回抽）；
3. 与支撑/界面收集、熨烫移除、塔避让的既有顺序耦合。

建议做法：**参数开关**（`glue.region = 'slicer' | 'computed'`），默认 `slicer`；新算法只影响 paint 块内容，外面结构不动。这样回退只需改一个参数。

## 7. lab 试验版（先只画，不写回）

- 打开：用第 N-1 层支撑 ∩ 第 N 层模型算出区域，2D 里画成半透明绿，叠在现有涂胶路径上；
- 生成一条**示意路径**（先只画线，不参与导出）；
- 对比指标：覆盖率（区域被现有路径覆盖多少）、最小余量、路径长度、抬笔次数。

指标达标再谈写回。

## 8. 什么时候回来做

「下方支撑余量」上线后统计误判：

- 有支撑却判成要抬（漏放）超过 10%，或
- 无支撑却判成不必抬（误放）出现一次以上，

就说明「跟着切片器的路径走」本身是错的——那时再启动本方案。
