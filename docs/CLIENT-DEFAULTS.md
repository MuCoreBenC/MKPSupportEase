# 客户端偏好的出厂值

## 1. 只此一份

`presets/client-defaults.toml` 的 `[Prefs]` 段。

两个消费者都 `include_str!` 它：

| 消费者 | 位置 | 用它做什么 |
|---|---|---|
| 内核 | `crates/postprocess/src/ir/types.rs` 的 `PrefsIr::default()` | 切 G-code 时没被预设覆盖的那几格 |
| 客户端 | `src-tauri/src/runtime/app_state.rs` 的 `PostprocPrefs::resolved()` | 设置页没填过的项显示什么 |

改默认值 = 改这一个文件。**别在代码里再写字面量**：`postproc_prefs` 里那条
`the_two_default_sets_agree` 咬的就是「两边不许各写一套」。镜像常量
（`Z_DWELL_DEFAULT` 等）只服务那条判据，不是第二份真值。

## 2. 生效时机

它是**编译期**进二进制的：

- 改完要**重新构建客户端**才进包；
- 已经装好的客户端**不受影响** —— 默认值只决定「没有偏好文件时初值是多少」；
- 老用户想套用新默认值，在设置里点一次「恢复默认」（把 `postproc` 整格写回 `null`）。

工作台「默认配置」页顶上那句写的就是这件事，别删。

## 3. 哪些项能配

只有 `[Prefs]` 段那 11 项 —— 它们是真改变切出来 G-code 的全部。

外观 / 切片 / 备份 / 高级 / 引导图是客户端私有偏好，不在这个文件里。工作台那一页
照客户端顺序把它们摆出来，标一句「只在客户端设置」，不假装能改。

调试动作那组（`debug_*`）也不在这里：它有自己那颗「恢复默认」，住
`src/app/settings/DebugPrefsModal.tsx`。

## 4. 与「出厂值只属于工作台」（AGENTS §1.6）的边界

§1.6 禁的是**预设参数的 `default` / `baseValue`** 被客户端接收与展示 ——
那几格是工作台算参数时的口径，可能是占位零。

这一份是**客户端偏好的初值**，不是预设参数、不进参数表、不参与 `presets generate`
的三层生成物。两者不冲突：前者归参数注册表，后者归这个文件。

## 5. 怎么改

两条路，选一条：

1. 工作台「默认配置」页 —— 写完进影子树，右上角「保存改动」才落 `presets/`；
   撤销 / 重做与其它页同一套栈。
2. 直接改 `presets/client-defaults.toml` —— 改完重编。

两条路都改同一份文件，不存在第二处要同步。
