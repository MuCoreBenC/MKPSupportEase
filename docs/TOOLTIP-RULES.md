# 悬停提示（tooltip）规则

> 只管**要不要有**。字数与禁用写法见 `COPY-STYLE.md` §3 / §4；
> 触发、延迟、位置与样式在 `src/components/tooltip/`（客户端与工作台共用一层）。

## 0. 判据只有一句

**悬停是最后手段，不是信息位。屏幕上已经说得清的，不再说一遍。**

删掉它，用户会不会做错？不会 ⇒ 不写。

"能不能说清楚"看**屏幕**，不看代码：标签已经写着「更新渠道」，气泡里再说「选择更新的发布渠道」＝ 没说；行里已经整段显示 `/Users/x/presets/a.toml`，气泡再念一遍 ＝ 没说。

## 1. 允许存在的只有五类（被动触发）

"被动"＝ 鼠标扫过它就会弹，用户没打算问。这五类之外的被动气泡一律不写。

| 类 | 触发物长什么样 | 气泡里写什么 | 上限 |
| --- | --- | --- | --- |
| 1 图标名 | 按钮没有可见文字（只有一个图标） | 它叫什么，或点了会怎样 | 8 字 |
| 2 截断值 | 元素真的是单行省略号（`text-overflow` / `line-clamp`） | **同一个完整值**，前面不加「路径：」「名称：」 | 原值 |
| 3 点不了的原因 | 按钮灰着，或点了没反应 | 卡在哪、先去改什么 | 30 字 |
| 4 危险动作的后果 | 删除 / 覆盖 / 写盘 | 一步之后发生什么 | 30 字 |
| 5 快捷键 | 有键位的动作 | 键位本身 | 一行 |

判定顺序按表从上往下：**先看触发物有没有字**（有字就基本用不上 1），再看是不是真截断（不是就删），最后才轮到 3/4/5。

### 1.5 第六类：主动触发（`?` 圆圈）

那颗 `?` 是**用户主动去问**的，不算"扫过就弹"，可以留：

- 只用在设置 / 高级项（`src/app/settings/**`）与参数行（`src/app/params/ParamRow.tsx`）；
- 讲「这一项管什么」「改了会怎样」，不讲机制；
- 每条 ≤ 60 字，一句。

列表行、动作按钮上不要新加 `?` —— 那里用可见的布局或一句状态词，不靠悬停。

## 2. 五类之外，看到就按这张表处置

| 看到什么 | 怎么处置 |
| --- | --- |
| 导航项 / 页签 / 按钮名的**同义复述**（`data-tip={x.label}`、`data-tip="放弃这一次的改动"` 挂在「放弃」上） | 删 data-tip；文字收起成图标时的那一份保留（见 §3.1） |
| 详情里**已经整段显示**的值：路径、SHA、文件名、型号 | 删 |
| 状态词的解释（「有改动没写进仓库」挂在「未保存」上） | 删 —— 状态词自己要说清后果 |
| 软件内部怎么运作（推进发布序号、影子树逐行对比、同步到云端） | 删；确实要讲就进折叠区 |
| 安抚与元话术（可撤销、不会丢、如实、正在读…） | 删 |
| 一句超过 50 字，或带「——」/括号补解释 | 砍成一句；砍不动说明它该进折叠区，不该进气泡 |
| 同一个事实在这一屏已经说了两处 | 只留用户做决定时看的那一处 |

## 3. 代码已经强制的那一条

### 3.1 说了的不弹

`TipLayer` 弹之前先比对两件事：

1. 这句话是否等于元素内部**此刻看得见**的某段文字（`display: none` 的标签不算）；
2. 那段文字有没有被截断。

都成立 ⇒ 不弹。

所以：

- `data-tip={x.label}` 在文字档、宽档**不会出现气泡**；侧栏收成图标（标签 `display: none`）时照常出现 —— 那时它是唯一的字。
- 被省略号截断的行会照常弹 —— 气泡是看到完整值的唯一入口。
- **不用**为了"别重复"去删图标按钮的 `data-tip`：它同时是读屏名（`TipLayer` 会给没有可见文字的元素补 `aria-label`）。

### 3.2 不要第二套

- 不写 `onMouseEnter` + `setState` 的自制气泡；样式、避让、延迟只有 `TipLayer` 一份。
- 不用原生 `title` 当气泡：延迟、位置、样式都不受控。按钮上写 `title` 会被 `Btn` 自动转成 `data-tip`，其余手写元素直接写 `data-tip`。

## 4. 改完自检（鼠标扫一遍这一屏）

1. 有没有"我已经看见了"的气泡？→ 删。
2. 气泡里的字，能不能从屏幕别处读到？→ 删。
3. 是不是在讲软件内部怎么运作？→ 删。
4. 有没有「——」或括号在补解释？→ 按 `COPY-STYLE.md` §4 改。
5. 有没有超过 50 字？→ 砍。

## 5. 盘点（随时可重跑）

```bash
rg -n "data-tip=|<Tip\b" src/app src/workbench src/components
```

- 主动触发只应出现在 `src/app/settings/**` 与 `src/app/params/ParamRow.tsx`；
  别的目录里出现 `<Tip` 就是违规。
- `data-tip={` 后面接 `.label` / `.title` / `.fileName` / `.path` / `.value` 的，是 §2 第一行那一类；
  代码已经让它不弹（§3.1），清理时顺手删掉，别让源码继续撒谎。

## 6. 存量清理顺序

| 档 | 清什么 | 为什么排这个位置 |
| --- | --- | --- |
| P0 | 导航 / 页签 / 标题 / 按钮名的复述 | 每次扫过都撞上，最烦；其中大部分已被 §3.1 挡住 |
| P1 | 详情区里整段可见的值（路径、SHA、文件名） | 量大，删起来机械 |
| P2 | 机制说明与安抚句 | 要判断"进折叠区还是删"，慢 |
| P3 | 设置页 `?` 的释义 | 主动触发，不烦人，最后再看 |

P0/P1 删之前先确认**没有截断**（§1 类 2）—— 拿不准就看 CSS 有没有 `text-overflow` / `line-clamp`。
